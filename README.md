# Final Fantasy Tactics - The Ivalice Chronicles - Egg Control Mod

## Functionality

This mod does not modify egg creation odds or the process for generating a new egg, other than preventing the creation of an egg based on what monster it would generate. The result of an egg is determined prior to the egg being added to your unit list, and it's at this time that this mod blocks adding that egg to the unit list (by simulating the effects of having no remaining open unit slots).

Substantially reduces the amount of annoying unit egg management that you have to do, as well as the amount of heartbreaking monster unit dismissals.

## Usage

Ensure that you have Reloaded-II installed and have registered the game FFT - The Ivalice Chronicles itself in Reloaded-II.

Drop the .7z file into Reloaded-II, then enable it.

Select which monsters will be allowed to be spawned via Configure Mod.
